Como funciona: altere um destino e clique em Publicar alterações. O painel atualizará o arquivo no GitHub automaticamente, após sua autorização. O QR impresso não muda. Este painel é público; nunca coloque seu token no código ou em arquivos do repositório.

Publicar destinos diretamente no GitHub

O token fica apenas na memória desta aba enquanto ela estiver aberta. Crie um token fine-grained com acesso somente a este repositório e permissão Contents: Read and write. Nunca compartilhe esse token com ninguém.

Para segurança, use este painel apenas no seu próprio dispositivo. A publicação pode demorar alguns minutos para aparecer no GitHub Pages.

Para cada QR Code, imprima o endereço permanente .../ir/?id=1, .../ir/?id=2 etc. O endereço de destino pode ser alterado sem reimprimir. Se estiver abrindo este painel como arquivo local, os links de QR ficarão disponíveis após publicar no GitHub Pages.

QR Codes criados no navegador por biblioteca externa; não exigem cadastro em um serviço de QR dinâmico. O GitHub Pages é público e sujeito aos limites e termos do GitHub.
